Full-Stack Application Deployment

Stack: React 18 + Node.js (Express) + PostgreSQL + PM2 + Nginx

Target Environment: Ubuntu Linux Server (VPS or Virtual Machine)

1. Architecture Overview

In modern production, we separate static file delivery from the API server and database:

[ User's Web Browser ] │ HTTP Port 80 ▼ ┌────────────────────────────────────────────────────────┐ │ NGINX Web Server │ │ • Directly serves React static assets (dist/) │ │ • Reverse-proxies /api/* calls to Node.js on port 5000│ └──────────────────────────┬─────────────────────────────┘ │ Internal Proxy ▼ ┌────────────────────────────────────────────────────────┐ │ PM2 Process Manager │ │ • Runs Node.js Express API in background (Port 5000) │ │ • Restarts on crashes, reboots, and updates │ └──────────────────────────┬─────────────────────────────┘ │ Internal Connection ▼ ┌────────────────────────────────────────────────────────┐ │ PostgreSQL Relational Database (Port 5432) │ │ • Stores Users, Menu Products, and Customer Orders │ └────────────────────────────────────────────────────────┘

Step 1: Connect to Server & Install Software

Connect to your remote Linux VPS using SSH:

ssh root@YOUR_SERVER_IP

Update system packages and install Git, Nginx, and build libraries:

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git nginx build-essential

Install Node.js 20 LTS and PM2 process manager:

# Install Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Install PM2 globally
sudo npm install -g pm2
pm2 -v

Step 2: Install & Configure PostgreSQL

sudo apt install -y postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql

Create the database and dedicated user:

sudo -u postgres psql

Execute in SQL prompt:

CREATE USER fooduser WITH ENCRYPTED PASSWORD 'MySecurePassword123!';
CREATE DATABASE food_order_db OWNER fooduser;
\q

In the EC2 security group, allow SSH only from your IP and inbound HTTP (80) and HTTPS (443) for visitors. Do not expose PostgreSQL (5432) or the Node API (5000) to the public internet.

Step 3: Clone Code from GitHub

sudo mkdir -p /var/www && sudo chown -R $USER:$USER /var/www
cd /var/www
git clone https://github.com/AbdurRehman5696/food-ordering-app.git
cd food-ordering-app

Step 4: Configure Backend Environment

cd backend
cp .env.example .env
nano .env

Set the PostgreSQL connection URL:

PORT=5000
DATABASE_URL="postgresql://fooduser:MySecurePassword123!@localhost:5432/food_order_db?schema=public"
JWT_SECRET="replace_with_a_random_secret_at_least_32_characters_long"
CLIENT_URL="http://YOUR_SERVER_IP"
SUPER_ADMIN_EMAIL=
SUPER_ADMIN_PASSWORD=

Generate a secret with openssl rand -base64 48. Keep backend/.env on the server only; do not commit it.

CLIENT_URL is the public IP or domain used in the browser. Keep localhost in DATABASE_URL when PostgreSQL runs on this EC2 instance. In production, Nginx forwards relative /api requests to backend localhost:5000; VITE_API_URL is only for local Vite development.

Set the super admin email and a unique password of at least 12 characters. Run node src/seed.js from backend/ after setting them. The legacy ADMIN_EMAIL and ADMIN_PASSWORD names are also supported.

Step 5: Setup Backend & Run DB Migrations

npm install
npx prisma generate
npx prisma migrate deploy
node src/seed.js     # Seeds the super admin, initial products and demo student login
cd ..

Step 6: Build React Frontend for Production

cd frontend
npm install
npm run build        # Compiles into frontend/dist/ folder
cd ..

Step 7: Launch Backend with PM2

Start the process using the included ecosystem configuration:

pm2 start ecosystem.config.js
pm2 status

Configure PM2 to automatically restart after server reboots:

pm2 startup systemd
# Copy and run the command printed in terminal (starts with sudo env PATH=...)
pm2 save

Step 8: Configure Nginx Web Server

The EC2/PM2 Nginx config is stored at deploy/nginx/food-ordering-app.conf. Install it using this exact site filename:

sudo cp deploy/nginx/food-ordering-app.conf /etc/nginx/sites-available/food-ordering-app

The config uses server_name _; for an EC2 public IP. For a domain, edit the directive in the copied config before enabling it.

Enable and restart Nginx:

    sudo ln -s /etc/nginx/sites-available/food-ordering-app /etc/nginx/sites-enabled/food-ordering-app
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl restart nginx
🎉 Congratulations! Visit http://YOUR_SERVER_IP in your browser to view and interact with the live application.

Day-2 DevOps: Zero-Downtime Redeployment

Whenever you push new code to GitHub, update the server with:

cd /var/www/food-ordering-app
git pull origin main
cd backend && npm install && cd ..
cd frontend && npm install && npm run build && cd ..
pm2 reload cravingbites-backend

Essential PM2 Commands

Command Description
pm2 status View status, CPU & memory usage of all processes
pm2 logs cravingbites-backend Stream live application logs
pm2 reload cravingbites-backend Reload server code with zero downtime
pm2 restart cravingbites-backend Stop and restart the process
pm2 monit Interactive dashboard inside terminal
